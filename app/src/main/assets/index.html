DeepSeek API

正在检查…

模型：deepseek-flash。密钥仅用于原生网络请求，通过 Android Keystore 加密保存。文字和选择的图片直接发送到 DeepSeek；本应用没有自己的服务器。最多 6 张图片、合计 16 MB，发送后清空输入框；最近对话中的最多 6 张图片（合计 16 MB）保存在应用私有目录供后续理解，清除对话时删除；失败或取消恢复待发附件；识别的课时表以结构化数据保存在本机。

始终开启思考，最低 low。强度越高，响应通常越慢、用量可能越多。

执行权限

正在检查…

通知策略访问用于系统允许的铃声切换，不等于开启勿扰模式。系统休眠可能限制密集闹钟；强行停止应用后，需重新打开以恢复调度。厂商后台限制可能影响执行。

后台守护

划掉最近任务后仍尽量保留执行进程，精确闹钟继续负责唤醒。请在系统设置中允许后台活动、取消电池限制；手机管家支持时，可将静律加入自启动白名单并锁定最近任务。

常驻服务不能保证绕过所有厂商清理。“强行停止”后仍需重新打开静律。守护可随时关闭，已保存的闹钟计划保留。

执行策略

系统无法始终区分修改来源。应用退出后只能在下次唤醒时比较模式；不会声称持续监测手动操作。
